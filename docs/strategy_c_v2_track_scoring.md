# 策略C v2 — AI赛道评分设计

## 一、AI产业链分层与A股映射

### Layer 1: 算力基础设施（确定性最高）
真正有业绩兑现的环节，受AI大模型训练/推理需求拉动：

| 环节 | 代表公司 | 业绩特征 | 行业映射 |
|------|---------|---------|---------|
| GPU/AI芯片 | 寒武纪、海光信息、景嘉微 | 高毛利，但利润波动大 | 半导体 |
| 服务器/液冷 | 浪潮信息、中科曙光、工业富联 | 营收弹性大，毛利低(5-15%) | 计算机设备 |
| 光模块 | 中际旭创、新易盛、天孚通信 | 800G放量，高成长 | 光学光电子 |
| PCB/连接器 | 沪电股份、深南电路 | 受益算力扩张 | 消费电子 |
| 存储 | 兆易创新、澜起科技 | HBM需求暴增 | 半导体 |

**量化特征**: 营收增长率>30%, 毛利率分化(芯片>光模块>服务器), 机构调研密集

### Layer 2: AI模型与平台（确定性中等）
技术壁垒高但商业化仍在爬坡：

| 环节 | 代表公司 | 业绩特征 |
|------|---------|---------|
| 大模型 | 科大讯飞、昆仑万维 | 研发投入大，短期亏损 |
| AI数据 | 海天瑞声 | 小众市场 |
| AI框架 | 拓尔思 | 低营收基数 |

**量化特征**: 营收增长波动大，研发费用占比高，概念>业绩

### Layer 3: AI应用落地（确定性分化）
部分领域已兑现业绩，部分还在讲故事：

| 环节 | 代表公司 | 业绩特征 |
|------|---------|---------|
| AI+安防 | 海康威视、大华股份 | 已有成熟商业模式 |
| AI+医疗 | 卫宁健康、创业慧康 | 概念为主 |
| AI+金融 | 东方财富、同花顺 | 有用户基础 |
| AI+教育 | 科德教育 | 不确定性高 |
| AI+办公 | 金山办公 | 订阅模式，业绩可见 |
| AI+机器人 | 埃斯顿、绿的谐波 | 早期阶段 |

## 二、赛道评分设计（纳入策略C v2评分体系）

### 2.1 行业景气度评分（Layer 1权重最高）

不是所有AI相关行业同等对待。根据产业链位置给不同基础分：

```
行业基础分(满分30):
  Tier1（算力核心）: 半导体/光学光电子 = 25分起
  Tier2（算力配套）: 计算机设备/消费电子/自动化设备 = 20分起
  Tier3（AI应用）: 软件开发/IT服务/通信设备 = 15分起
  其他行业: 10分起
```

### 2.2 个股赛道评分（在基本面评分基础上加成）

```
赛道加成(满分20分，叠加在基本面80分之上):
  A. 营收加速（AI拉动）:
     - 营收yoy > 30%: +8分
     - 营收yoy > 15%: +4分
     - 营收yoy 连续2期加速: +4分（额外）
  
  B. 行业资金认可:
     - 近20日行业资金净流入 > 0: +4分
     - 近5日行业涨幅前30%: +4分
  
  C. 机构信号:
     - 近30天机构调研 >= 3次: +4分
```

### 2.3 真假AI识别（防止概念炒作）

```
概念股过滤（扣分项）:
  - 营收增长 < 5% 但股价涨幅 > 50%（概念炒作）: -10分
  - ROE < 5% 且无改善趋势（不赚钱的公司）: -10分
  - 主营业务与AI无关（蹭热点）: -20分
```

## 三、策略C v2完整评分体系（满分100）

```
A. 盈利能力（25分）
   ROE > 12%: +10分 | ROE 8-12%: +5分
   净利率 > 15%: +8分 | 净利率 8-15%: +4分
   毛利率 > 40%: +7分 | 毛利率 25-40%: +3分

B. 成长性（25分）
   营收yoy > 30%: +10分 | 营收yoy 15-30%: +5分
   利润yoy > 30%: +10分 | 利润yoy 15-30%: +5分
   连续2期加速: +5分

C. 财务健康（15分）
   负债率 < 40%: +8分 | 负债率 40-60%: +4分
   净利率>0且改善: +7分

D. 赛道/行业（20分）
   行业景气度基础分(见2.1): 最高30分 → 归一化到15分
   营收加速(AI拉动): +5分（见2.2A）

E. 增持/信号（15分）
   大股东增持: +5分
   行业资金流入: +5分
   机构调研密集: +5分

合计: 25+25+15+20+15 = 100分
及格线: 60分（与蓝图一致）
```

## 五、关键设计决策

1. **赛道不是唯一标准**：茅台没有AI概念但基本面极好，照样85分。赛道是加分项不是门槛。
2. **概念股会自动过滤**：中科曙光虽然"算力概念"，但营收-8.4%，在成长性维度就拿不到分。
3. **负债率要分行业看**：宁德65%负债在电池行业是正常的，扣分要给缓冲。
4. **ROE的Q1陷阱**：紫光国微Q1的ROE只有2.4%（年化约10%），不能单看一季度。应取最近年报或TTM。
