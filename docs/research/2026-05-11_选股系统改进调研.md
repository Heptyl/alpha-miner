# 金牌交易员 — 选股系统改进调研报告

## 问题诊断

2026-05-11复盘：创业板+3.65%、98涨停，ML候选6只5只跌，0个买点触发。

| 维度 | 现状 | 问题 |
|------|------|------|
| ML模型 | 79个纯技术特征,得分0.008-0.011 | ≈随机选股,无区分度 |
| 数据时效 | 基于3天前(5/8)数据 | 刻舟求剑 |
| 过滤逻辑 | 纯防守(PE/流动性/涨幅上限/ST) | 高潮日挡掉强势股 |
| 买点信号 | 固定3种,刚性条件 | 98涨停日触发不了 |

## 一、成熟项目调研

### 1. 微软 Qlib (★16k+)

**核心思路**: Alpha挖掘框架,不是选股器,但提供了因子工程最佳实践

**可借鉴**:
- **因子自动挖掘**: 用遗传算法/表达式树自动搜索有效因子
- **IC/ICIR评估体系**: IC>0.03, ICIR>0.5 才算有效因子
- **数据标准化**: 特征工程pipeline,缺失值/归一化/截面排名
- **多任务模型**: 预测涨跌幅+排序,不只是一个score

**对我们的启发**: 
- 当前79个特征没有经过IC筛选 → 应该先算每个特征的IC,去掉IC<0.03的噪声特征
- 模型应该预测排名(截面排序)而不是绝对涨跌幅
- 应该加入截面因子: 比如个股涨幅在板块内的排名

### 2. vnpy CTA策略模块 (★25k+)

**核心思路**: 事件驱动的CTA策略框架,内置多种经典短线策略

**可借鉴**:
- **突破策略**: 唐奇安通道突破(前N日最高价突破),不是RSI/MACD那套
- **均线策略**: EMA交叉(快线上穿慢线),比我们用的MA20判断更敏感
- **布林带策略**: 价格触及下轨后回归中轨
- **仓位管理**: Kelly公式/固定比例,根据波动率动态调仓
- **多时间框架**: 日线趋势 + 小时线入场,不是单用日线

**对我们的启发**:
- 买点信号不应该只看涨跌幅+量比,应该看**价格突破前高**
- 高潮日应该用**通道突破策略**(前20日最高价突破),而不是RSI条件
- 应该支持多策略切换,不是一套固定条件

### 3. 聚宽/米筐 社区短线策略

**核心思路**: 众筹策略社区,大量A股实战验证的策略

**经典A股短线策略**(社区验证):

#### 策略A: 涨停板战法 (最经典)
```
1. 昨日涨停 + 今日不跌 = 强势确认
2. 连板股(2连板+)的板块内联动股
3. 涨停时间越早(10点前)越强
```

#### 策略B: 板块轮动 (机构常用)
```
1. 计算每个板块当日涨幅
2. 取涨幅TOP3板块
3. 在TOP板块内选: 龙头(涨幅最大) + 补涨(涨幅<板块均值)
```

#### 策略C: 资金流向 (主力追踪)
```
1. 主力净流入TOP20
2. 大单占比 > 30%
3. 连续3日主力净流入
```

#### 策略D: 龙头战法 (短线之王)
```
1. 当日涨停股
2. 按连板高度排序
3. 龙头首阴(首次收绿)时低吸
```

## 二、学术论文调研

### 1. 涨停板效应 (A股特有)

**核心发现** (多篇论文一致结论):
- 涨停次日平均收益+1.5%~3%,胜率60-65%
- **连板股**(2连板+)次日表现 > 首板股
- **封板时间**: 10:00前封板 → 次日表现最好
- **开板次数**: 不开板(一字板) > 开板1次 > 多次开板
- **板块效应**: 同板块涨停数>3 → 板块内个股次日溢价更高

**可用因子**:
- `zt_consecutive`: 连板天数 (越大越好)
- `zt_sealed_time`: 封板时间 (越早越好)  
- `zt_board_count`: 同板块涨停数 (越多板块越热)
- `zt_open_times`: 开板次数 (越少越好)

### 2. 动量因子 (Momentum)

**核心发现**:
- A股短周期动量(1周-1月)有效,长周期(6-12月)反转
- **截面动量**: 个股涨跌幅在全市场的排名,比绝对涨跌幅更有预测力
- **行业动量**: 行业指数的短期动量比个股更稳定
- **动量崩溃**: 熔断/暴跌时动量失效,需要市场状态判断

**可用因子**:
- `ret_5d_rank`: 5日涨幅在市场内排名百分位
- `industry_mom_5d`: 所属行业5日涨幅
- `vol_adj_momentum`: 波动率调整后的动量(更稳健)

### 3. 市场情绪/Regime Detection

**核心发现**:
- **涨停数量**是最直接的情绪指标
- 高潮期(涨停>80): 追涨策略胜率70%+,但持续性存疑
- 冰点期(涨停<30): 任何策略都容易亏,应空仓等待
- **情绪转换点**最有价值: 冰点→复苏时买入,高潮→退潮时卖出

**我们的92科比四阶段法**已经是对的框架,但没落地到选股逻辑里:
- 冰点: 空仓等待,只看超跌反弹
- 复苏: 半仓,做板块龙头首板
- 高潮: 满仓,追连板龙头
- 退潮: 减仓,做低位补涨

## 三、改进方案设计

### 核心思路: 从"ML预测型"转向"市场驱动型"

当前: ML打分 → 过滤 → 等买点 (被动)
改进: 市场状态 → 选策略 → 选板块 → 选个股 → 执行 (主动)

### 架构设计

```
[市场状态判断]
  ├── 情绪指标: 涨停数/炸板率/连板高度
  ├── 大盘趋势: 指数MA/成交量
  └── 资金方向: 北向/主力净流入
         │
         ▼
[策略选择] (根据市场状态)
  ├── 冰点 → 超跌反弹策略
  ├── 复苏 → 板块龙头首板
  ├── 高潮 → 连板战法/追涨
  └── 退潮 → 低吸补涨
         │
         ▼
[板块筛选] (选出当天最热3个板块)
  ├── 板块涨幅排名
  ├── 板块内涨停数
  ├── 板块主力净流入
  └── 概念热度(新闻/政策)
         │
         ▼
[个股选择] (在热门板块内选)
  ├── 龙头: 涨幅最大/连板最高
  ├── 补涨: 涨幅<板块均值但有资金流入
  ├── 关联: 同板块内跟随上涨
  └── ML辅助: 技术面过滤(不追ST/亏损/流动性差)
         │
         ▼
[买点执行] (根据策略类型)
  ├── 高潮日: 放宽条件(涨幅1-5%+板块热门即可)
  ├── 冰点日: 收紧条件(超跌+RSI<25+缩量企稳)
  └── 复苏日: 板块龙头回踩MA5
```

### 具体实现路径

#### Phase 1: 数据先行 (最紧急)
1. **涨停池实时采集**: 每天9:35开始每10分钟采集涨停/炸板数据
2. **板块热度计算**: 从涨停池提取当日热门板块(涨停数≥3)
3. **资金流向**: 主力净流入排行(已有fund_flow表,需每日更新)

#### Phase 2: 市场状态引擎
1. 复用92科比四阶段(已在system_map里描述但未代码化)
2. 输入: 涨停数/炸板率/连板高度 → 输出: 冰点/复苏/高潮/退潮
3. 每个阶段对应不同的: 仓位上限/买入条件/止损策略

#### Phase 3: 候选股生成重构
1. 不只靠ML TOP20,加入多个来源:
   - 涨停池关联(昨日涨停今日不跌)
   - 板块龙头(TOP3板块内涨幅最大)
   - 资金追捧(主力净流入TOP20)
   - ML辅助(技术面OK)
2. 合并去重后形成30-50只宽候选池
3. 再根据市场状态用不同权重排序

#### Phase 4: 买点信号动态化
1. 高潮日: 放量突破条件放宽(涨幅>1%+板块热门即可)
2. 冰点日: 只做超跌反弹(跌幅>-5%+RSI<25+缩量)
3. 复苏日: 板块龙头回踩MA5
4. 退潮日: 基本不开新仓

## 四、预期效果

| 情景 | 改进前 | 改进后 |
|------|--------|--------|
| 98涨停高潮日 | ML选6只冷门股,0买点 | 选热门板块龙头,多只触发买点 |
| 冰点日(<30涨停) | 同上(无差别) | 空仓或超跌反弹 |
| 板块轮动日 | 选不出板块龙头 | 自动追踪资金流入板块 |
| 连板行情 | 完全错过 | 涨停关联+补涨策略 |
