## 一、学到了什么 — 5个核心知识点

### 1. 量价背离的四种经典形态及其A股实战含义

**核心原理**: 价格趋势需要成交量确认。当量价出现背离时，往往预示趋势反转。

| 形态 | 价格 | 成交量 | 含义 | 信号强度 |
|------|------|--------|------|---------|
| 顶背离 | 创新高 | 低于前高点的量 | 上涨动力衰竭 | ⭐⭐⭐ 强卖出 |
| 底背离 | 创新低 | 低于前低点的量 | 抛压枯竭 | ⭐⭐⭐ 强买入 |
| 放量滞涨 | 连续上涨 | 连续放量 | 主力出货嫌疑 | ⭐⭐⭐ 卖出 |
| 缩量阴跌 | 持续下跌 | 逐步缩量 | 跌势未尽(未到底) | ⭐⭐ 观望 |

**对Alpha Miner的启发**: 
- 当前 `alpha158.py` 中的 `TCORR_5/10/20` 因子计算了收益率与成交量的相关性，这可以间接捕捉量价背离
- **但缺少直接的量价背离识别因子**，比如"价格创新高但成交量未创新高"的离散信号
- 应该新增一个 `VOL_PRICE_DIVERGENCE` 因子

### 2. ATR(平均真实波幅)的多重用途 — 不只是止损

**ATR的本质**: 衡量N日内价格波动的平均幅度（考虑跳空缺口）。

**ATR的5大实战用途**:
1. **动态止损**: 止损位 = 买入价 - 1.5×ATR(14) ← 项目P3待实施!
2. **仓位管理**: 每笔仓位 = 风险预算(总资产×1%) / ATR ← 与凯利公式配合
3. **波动率过滤**: ATR_RATIO = ATR(14)/收盘价，过高(>5%)=投机股需谨慎
4. **突破确认**: 价格突破前高 + ATR扩大 = 有效突破；突破前高 + ATR缩小 = 假突破
5. **趋势强度**: ATR递增 + 价格上涨 = 强趋势；ATR递减 = 趋势减弱

**项目现状审查**:
- ✅ `alpha158.py` 已计算 `ATR_5`, `ATR_14`, `ATR_RATIO`
- ✅ `technical.py` 已有 `_compute_atr()` 函数
- ❌ `risk_manager.py` 仍使用固定8%止损，**未使用ATR**
- ❌ 仓位管理未考虑ATR（固定每只25%上限）
- ❌ 无突破有效性确认（未结合ATR判断真假突破）

### 3. 支撑阻力的多层次识别法 — 不只是前高前低

**A股实战中有效的支撑阻力位**:

| 类型 | 识别方法 | 强度 | A股特别说明 |
|------|---------|------|------------|
| 前高/前低 | 近20/60日极值 | ⭐⭐⭐ | 整数关口有"磁吸效应"(如10/15/20元) |
| 缺口 | 日线跳空缺口 | ⭐⭐⭐ | 缺口必补是A股规律，未补缺口=强支撑/阻力 |
| 均线 | MA5/MA10/MA20/MA60 | ⭐⭐ | 20日线(月线)和60日线(季线)最重要 |
| 成交密集区 | 换手率>10%的价格区间 | ⭐⭐⭐ | 高换手=筹码交换密集=强支撑/阻力 |
| 涨停价 | 涨停板价位 | ⭐⭐ | 涨停后次日有回踩涨停价的惯性 |

**项目现状审查**:
- ✅ `technical.py` 的 `_compute_support/resistance` 用了均线和近期极值
- ❌ **未识别跳空缺口**
- ❌ **未考虑成交密集区**
- ❌ **未考虑整数关口磁吸效应**
- ❌ **未考虑涨停价回踩支撑**

### 4. K线形态的量化识别 — 从图形到因子

**经典形态的量化定义**:

| 形态 | 量化条件 | A股胜率(统计经验) |
|------|---------|-----------------|
| 早晨之星 | (1)长阴线 body>2%ATR (2)十字星 \|open-close\|<0.5%ATR (3)阳线 body>50%阴线 | ~60% |
| 乌云盖顶 | (1)长阳线 (2)高开>前收 (3)收盘深入前阳50%以下 | ~58% |
| 锤子线 | 下影线>2×实体, 上影线<0.5×实体 | ~55% |
| 吞没形态 | 当日实体完全包含前日实体+方向相反 | ~57% |

**关键发现**: Alpha158的K线因子(`KMID`, `KLEN`, `KMID2`, `KSFT`)实际上是对K线形态的**连续化编码**，而非离散形态识别。这有优势（不丢失信息），也有劣势（无法识别"锤子线"这种组合条件）。

**改进方向**: 可以新增一组离散的K线形态因子：
```python
# 锤子线因子
HAMMER = (lower_shadow > 2 * body) & (upper_shadow < 0.5 * body) & (body > 0)
# 吞没因子  
ENGULFING = (body > prev_body) & (direction != prev_direction)
# 十字星
DOJI = abs(open - close) < 0.1 * (high - low)
```

### 5. 成交量的领先性 — 量先价行的实证逻辑

**核心原理**: 在A股T+1制度下，成交量是最有信息量的指标。

| 量价关系 | 出现时机 | 领先天数 | 可操作性 |
|---------|---------|---------|---------|
| 底部放量单针 | 超跌后 | 领先1-3日 | ⭐⭐⭐ 可直接买入 |
| 温和放量突破 | 盘整末期 | 领先1-2日 | ⭐⭐⭐ 可追入 |
| 放量长上影 | 上涨末期 | 领先1-2日 | ⭐⭐⭐ 应卖出 |
| 缩量横盘 | 上涨中继 | 领先3-5日 | ⭐⭐ 需等待确认 |
| 天量天价 | 疯狂阶段 | 领先0-1日 | ⭐⭐⭐ 立即离场 |

**量比因子的优化思路**:
- 项目当前的 `VOLUME_D`(当日量/5日均量)和 `TURNOVER_D`是基本量比
- **缺少"量比趋势"**: 应增加 `VOL_RATIO_TREND = 5日量比均值 / 20日量比均值`
- **缺少"放量持续性"**: 连续N日量比>1.5 的天数
- **缺少"量价协同方向"**: 量价同涨/同跌 vs 量价背离，应分开计分

## 三、可立即落地的改进建议

### 建议1: 实现P3 — ATR动态止损（⭐⭐⭐ 最高优先级）

**现状**: `risk_manager.py` 使用 `DEFAULT_STOP_LOSS_PCT = 0.08` 固定8%止损

**问题**: 
- 高波动股(如涨跌停板股) 8% 很容易被洗出
- 低波动股(如大盘蓝筹) 8% 的止损线太宽，亏太多

**方案**: 
```python
# 在 risk_manager.py 中修改 check_stop_loss()
# 新增 ATR-based 止损:
atr = self._get_atr(code, as_of)  # 从 daily_price 计算 ATR(14)
stop_price = buy_price - 1.5 * atr  # 止损价 = 买入价 - 1.5倍ATR
# 同时设上下限: 最低3%, 最高12%
```

**预期效果**: 高波动股止损空间更大(10-12%)，低波动股更紧(3-5%)，减少无效止损

### 建议2: 在 alpha158.py 中增加3个量价背离因子

```python
# 1. 量价背离因子: 价格创新高但量未创新高
g["VOL_PRICE_DIV_5"] = (
    (c > _ts_max(c, 5).shift(1)).astype(float) - 
    (v > _ts_max(v, 5).shift(1)).astype(float)
)  # 正值=顶背离, 负值=底背离

# 2. 放量持续性: 连续N日量比>1.5
vol_ratio = v / _ts_mean(v, 20)
g["VOL_PERSIST"] = _ts_sum((vol_ratio > 1.5).astype(float), 5)

# 3. 量价协同方向: 
g["VOL_PRICE_SYNC"] = ((ret > 0) == (v > _ts_mean(v, 5))).astype(float)
# True=量价同向(趋势健康), False=量价背离(警惕反转)
```

### 建议3: 增强 technical.py 的支撑阻力识别

```python
# 缺口识别
gaps = df[df['low'] > df['high'].shift(1)]  # 向上缺口
support_from_gap = gaps['low'].min()  # 缺口下沿=支撑

# 整数关口磁吸效应
round_levels = [round(current / 5) * 5 for _ in range(1)]  # 5的整数倍
nearest_round = min(round_levels, key=lambda x: abs(x - current))
```
