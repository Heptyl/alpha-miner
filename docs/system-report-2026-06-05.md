## 二、三大策略详情

### 2.1 策略A：龙头首阴反包（3万/3只）

**逻辑**：
1. 找绝对龙头（连板≥2的票，龙头评分=连板30+梯队20+封板20+市值15+形态15）
2. 龙头首次收阴（首阴日）
3. 次日高开2%以上+翻红确认 → 买入
4. 持仓2-3天，涨停豁免
5. 止损：跌破首阴最低价×0.98
6. Trailing：3%/退潮2%/冰点1.5%

**回测**：20笔PF=17.64（但样本极小）

**实盘**：4笔 2胜50% 盈亏+380 ✅ 唯一正收益策略

### 2.2 策略B：暴跌日好公司狙击（1万/1只）

**逻辑**：
1. 大盘暴跌日（均跌>2%）
2. 个股跌>5%但基本面好（ROE>10%）
3. 次日低开买入
4. 持仓7天
5. 止损-6%，trailing 5%/退潮3%/冰点2%

**旧版(追涨停回踩)**：已废弃，PF=1.06不显著
**新版(暴跌日狙击)**：T+1回测PF=1.29，胜率51.3%

**实盘**：
- 旧版策略B：10笔 3胜30% 亏-671
- 回踩低吸：9笔 4胜44% 亏-764
- 低开反弹：5笔 1胜20% 亏-704
- 暴跌日狙击(新)：1笔 1胜100% 赚+81
- **合计B系**：25笔 9胜36% 亏-2,058

### 2.3 策略C：趋势牛股（5万/3只）

**逻辑**：
1. 基本面驱动模式：AI赛道+量比≥3+F-Score≥55
2. 三层筛选：Layer1量比 → Layer2基本面(F-Score) → Layer3技术信号
3. 精选评分卡打分：IC权重+龙虎榜+北向+解禁+新闻情感
4. 止损-10%，目标收益+10%
5. 最长持仓5天

**回测**：T+1回测PF=3.85，胜率67.6%

**实盘**：6笔 1胜17% 亏-2,643 ❌ **最差策略**
- 信音电子+769（唯一赢家）
- 北京君正-2,128（单笔最大亏损-12.5%）
- 联得装备×2次共亏-583
- 瑞芯微-530，信音电子(第二次)-171

## 三、智能模块

### 3.1 TradingBrain（交易员大脑）

**架构**（6/3重构，参考TradingAgents ICML2025）：

```
买入前评分流程：

  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
  │ 市场环境  │ │ 个股质量  │ │ 策略匹配  │ │ LLM辅助  │
  │ (25分)   │ │ (35分)   │ │ (20分)   │ │ (20分)   │
  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘
       │            │            │            │
       └────────────┴─────┬──────┴────────────┘
                          │
                    数据总分(0-100)
                          │
              ┌───────────┼───────────┐
              │           │           │
          >=65放行    50-65观察区    <50拦截
          (不调LLM)   (调LLM辅助)   (不调LLM)
```

**市场环境(25分)**：
- 涨跌比：冰点0/退潮5/正常10-15/高潮20
- 权重翻红比例
- 反转信号

**个股质量(35分)**：
- 精选评分卡(0-20分)：映射公式 `(F-Score-30)*0.40`
- 交易记忆胜率(0-10分)
- 历史同票盈亏(-3~+5分)

**策略匹配(20分)**：
- 信号强度
- 策略历史PF

**LLM辅助(20分)**：
- 只在50-65观察区调用
- GLM-5.1(智谱旗舰)做综合判断
- LLM失败不加分

**硬规则拦截**（任何评分都不过）：
- 记忆胜率<35%且>=5条记忆
- 冰点+非策略C
- 5分钟拦截缓存

**当前问题**：
- 市场维度：正常72%涨跌比只给5/25分 ← 偏严
- 个股维度：F-Score=63映射到16/35分 ← 映射系数偏严
- 策略维度：固定10/20 ← 无区分度
- 结果：正常行情+合格候选总分=28-31/50，全部被拦

### 3.2 精选评分卡（selection_score.py）

**5维加权评分**：
1. IC权重（因子预测力）— 主分
2. 龙虎榜席位加减分
3. 北向/主力资金加减分
4. 解禁风险减分
5. 新闻情感加减分(+3/-3)

**阈值**：60分及格，55分最低

### 3.3 交易记忆（trade_memory.py）

- 每笔交易记录买卖价/盈亏/策略/市场环境
- 查询：按股票代码/策略/市场阶段
- 胜率计算：>=5条记忆才出胜率
- 大脑降级：LLM失败时先查记忆胜率做决策

### 3.4 市场感知（market_perception.py）

- 板块归属（自动识别个股所属板块）
- 盘面风格（大盘强/均衡/小盘强）
- 领涨领跌板块TOP5
- 反转信号检测（冰点→正常）
- 个股涨因LLM分析

### 3.5 情绪判定（daemon_risk.py）

**数据源**：
1. 首选：ulist涨跌家数（API不稳定，WSL固有问题）
2. 备选：涨停数+盘面感知模块推算

**判定规则**（涨跌比为主）：
- 冰点：<30%
- 退潮：30-40%
- 正常：40-75%
- 高潮：>75%

**6/5修复**：
- ulist失败时用上一轮成功的值（不再跳到50%）
- 连续2次同一phase才切换（平滑跳动）

### 3.6 新闻情感（sentiment_analyzer.py）

- 东财新闻API获取个股/行业新闻
- 7级情感分类（very_positive → very_negative）
- 精选评分卡中+3/-3分

## 四、风控体系

### 4.1 四级熔断

| 级别 | 触发条件 | 动作 |
|------|----------|------|
| L1 | 总浮亏≤-900(50%) | 停止买入 |
| L2 | 日亏≥-1800(2%) | 停止买入+检查持仓 |
| L3 | 连续3笔亏损 | 暂停1小时 |
| L4 | 周回撤≥5% | 暂停至下周一 |

### 4.2 退潮保护

- 涨跌比<30%：冰点，策略A/B暂停买入，仅策略C走独立路径
- 涨跌比30-40%：退潮，持仓检查
  - 盘中跌>3%且退潮→卖出预告（1分钟后执行）
  - 盘中跌>5%且冰点→立即卖出
- 极端退潮清仓后：30分钟冷却期，暂停所有买入

### 4.3 Grace Period（开盘保护期）

- 09:30-10:00止损只记录不执行
- 等波动消化后10:00二次评估
- 硬止损-10%即使在Grace期也执行
- 回测验证：净效果+0.52%/笔

### 4.4 其他风控

- 行业集中度：同行业最多2只
- 高价股超配：单只≤25%仓位
- 滑点0.1%，手续费万2.5，印花税万5

北京君正一笔亏掉总亏损的49%。176元的票-12.5%止损=每股亏21元×100=-2,100。

**根因2：退潮期不该买但还在买（占亏损41%）**

6笔退潮保护/退潮止损卖出，全部亏损共-1,771。说明系统在退潮/冰点时还在建仓，然后被退潮保护强制卖出。

**根因3：策略B旧版+回踩低吸17笔亏-1,435**

旧版策略B（追涨停回踩）已废弃但历史亏损已造成。新版暴跌日狙击只跑了1笔（赚+81），数据太少无法判断。

**根因4：胜率34%，盈亏比0.4:1**

12笔盈利平均+549，23笔亏损平均-386。盈利不够覆盖亏损。需要胜率50%+或盈亏比2:1以上才能盈利。
